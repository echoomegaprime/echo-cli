# Community code of conduct

This project is the official command-line client for Echo Prime Technologies and handles
user API keys, and expects high-trust collaboration in proportion to that responsibility.

## Our standard

Be accurate, respectful, and evidence-led. Critique code and claims, not people. Protect
credentials. Make room for questions, explain tradeoffs, and correct mistakes plainly.
Harassment, discrimination, threats, doxxing, impersonation, deliberate disruption, and secret
disclosure are not acceptable.

## Enforcement

Report conduct concerns privately to `conduct@echo-op.com`. Include links or screenshots when
safe, but do not forward credentials or restricted evidence. Maintainers may edit, hide, lock,
or remove content and may restrict participation when necessary to protect the project and its
community. Reports are handled as confidentially as practical.

This policy applies in repository discussions, reviews, project spaces, and other forums where a
participant represents the project.
