# Echo icon

Created with the built-in image generation tool for this workspace. The generated
asset is installed in the sidebar, welcome view, browser favicon and touch icon.

Design brief: a premium platinum Echo/omega emblem, polished dimensional metal,
amethyst accents, controlled purple light and a deep black background. It should
read clearly as an app icon and fit the dark workspace without added text.

`Echo-icon.png` is the delivered source asset; `app/static/echo-icon.png` is the
served copy. This brief describes the delivered design, rather than claiming to
reproduce the exact original generation prompt.
